# HomeLibrary

ASP.NET Core приложение «Домашняя библиотека» с SQL Server, Dapper и хранимыми процедурами

## Запуск

Для запуска нужны Docker и Docker Compose

```bash
docker compose up --build
```

SQL Server, база данных, миграции и web-приложение запускаются автоматически

После запуска приложение доступно по адресу http://localhost:18080
